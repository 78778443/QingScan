# 工具回调方案设计

## 一、核心思路

```
┌─────────┐    启动命令     ┌─────────┐
│  平台   │ ───────────────→│  插件   │
│         │   task_id       │         │
│         │   target        │         │
│         │   callback_url  │         │
└────┬────┘                 └────┬────┘
     ↑                           │
     │      回调API              │
     └───────────────────────────┘
```

- 平台只管**启动**和**接收**
- 插件负责**执行**和**回调**
- **数据格式自由**，平台不解析

---

## 二、回调API

### 状态更新 - POST `/api/callback/status`

```json
{
  "task_id": 123,
  "status": "running",
  "progress": 50,
  "message": "正在扫描..."
}
```

| 字段 | 必填 | 说明 |
|------|------|------|
| task_id | 是 | 任务ID |
| status | 是 | `running` / `completed` / `failed` |
| progress | 否 | 进度 0-100 |
| message | 否 | 状态消息 |

### 结果提交 - POST `/api/callback/result`

```json
{
  "task_id": 123,
  "status": "completed",
  "data": "任意内容",
  "data_type": "asset"
}
```

| 字段 | 必填 | 说明 |
|------|------|------|
| task_id | 是 | 任务ID |
| status | 是 | `completed` / `failed` |
| data | 否 | 任意数据 |
| data_type | 否 | 类型标识（自定义） |
| message | 否 | 失败时的错误信息 |

## 三、数据库

### scan_tool 表

```sql
CREATE TABLE scan_tool (
    id INT AUTO_INCREMENT PRIMARY KEY,
    tool_name VARCHAR(50) NOT NULL,
    tool_label VARCHAR(100),
    description VARCHAR(500),
    start_command TEXT,          -- 启动命令模板
    is_enabled TINYINT DEFAULT 1
);
```

**start_command 占位符：**

| 占位符 | 替换为 |
|--------|--------|
| `{task_id}` | 任务ID |
| `{target}` | 扫描目标 |
| `{callback_url}` | 回调地址 |

### scan_result 表

```sql
CREATE TABLE scan_result (
    id INT AUTO_INCREMENT PRIMARY KEY,
    task_id INT NOT NULL,
    data MEDIUMTEXT,             -- 原始数据
    data_type VARCHAR(50),       -- 类型标识
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

---

## 四、流程

```
1. 平台替换占位符，执行 start_command
2. 插件启动，回调 /status
3. 插件执行扫描
4. 插件回调 /result 提交数据
5. 平台原样存储到 scan_result.data
```

## 五、插件示例

```python
#!/usr/bin/env python3
import argparse
import requests

def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("--task-id", required=True, type=int)
    parser.add_argument("--callback", required=True)
    parser.add_argument("--target", required=True)
    args = parser.parse_args()

    # 启动
    requests.post(f"{args.callback}/status", json={
        "task_id": args.task_id,
        "status": "running"
    })

    try:
        # 执行
        result = do_scan(args.target)

        # 完成
        requests.post(f"{args.callback}/result", json={
            "task_id": args.task_id,
            "status": "completed",
            "data": result
        })
    except Exception as e:
        requests.post(f"{args.callback}/result", json={
            "task_id": args.task_id,
            "status": "failed",
            "message": str(e)
        })

if __name__ == "__main__":
    main()
```
