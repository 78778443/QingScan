数据表

- scan_tool - 工具配置表（从数据库读取）
- scan_target - 扫描目标
- scan_task - 扫描任务
- scan_result - 扫描结果
- llm_analysis - LLM分析结果

CLI使用

# 1. 初始化工具到数据库（只需执行一次）
./new_cli -init

# 2. 列出可用工具
./new_cli -list

# 3. 执行扫描（完整流程：添加目标→选择工具→扫描→存储→LLM分析）
./new_cli -t "http://example.com/test.php?id=1" -s sqlmap

# 4. 查看任务列表
./new_cli -tasks

# 5. 查看扫描结果
./new_cli -results

# 6. 单独执行LLM分析
./new_cli -analyze
